## Implemented
- Preserve home canonical and existing HTML, CSS, JavaScript and Supabase backend.
- 10 unique, service-specific indexable pages with own canonical title, meta description, H1, relevant Dutch content, FAQs, breadcrumbs, JSON-LD and clear contact CTA.
- A visible home service hub linking directly to all new URLs.
- Existing historical redirect rules now permit real landing page directories while keeping the old redirect if a directory is missing.
- `sitemap.xml` contains home and 10 new canonical URLs, excludes legal noindex and admin pages.

## Required prepublication checks
1. Upload all page directories and `css/seo-pages.css` to Hostinger first; then homepage, `.htaccess`, sitemap as one controlled release. Never submit unpublished sitemap URLs.
2. Verify 200 statuses, unique title and H1, self canonical, CSS assets, links, mobile layout for each route; verify legacy 301 recovery and www redirect.
3. Verify dynamic car inventory, image galleries, admin login and all front-end functionality still operate. No changes to database or auth were made.
4. Submit sitemap via connected GSC Wizard only after live URLs return 200. GSC indexing is not guaranteed.
5. Inspect sample URLs in GSC and compare same-length 28-day periods by query/page/country/device.
6. After Supabase-to-Hostinger migration is finished, build stable, server-rendered individual vehicle detail pages based on live inventory, stock status and correct canonical URLs. Never create stale vehicle promises.
7. Audit Google Business Profile business categories, services, photos, address, hours and location; its account was not connected here.

## Excluded misleading targets
No unsupported car rental, guaranteed 24/7 towing, fixed garage service pricing, car glass/paint repair, or invented warranty/vehicle availability. No search volume or CPC claims without Keyword Planner.
