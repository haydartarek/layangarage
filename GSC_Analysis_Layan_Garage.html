Critical Issues Found
🚨 Issue #1 — CRITICAL: Two separate URLs indexed by Google
https://www.layangaragebv.be/ → 692 impressions · position 4.3 · 28 clicks
https://layangaragebv.be/ → 564 impressions · position 23.43 · 27 clicks

Google treats these as two different pages and splits domain authority between them. This explains the erratic position swings. Total combined impressions = 1,256 — all of that power should flow into one URL. Fix: 301 redirect + canonical alignment (see Fix #1 below).
⚠ Issue #2: Old WordPress sub-pages still indexed — zero CTR despite top-5 positions
GSC shows 7 sub-page URLs (/diensten/motordiagnose/, /verkoop-wagens/, etc.) ranked at positions 3–7 with 500+ combined impressions but near-zero clicks. Since Google only ranks pages that return HTTP 200, these are live WordPress pages still on the server with outdated title tags and meta descriptions — causing users to see them in results and not click. Fix: redirect or update each page (see Fix #2 below).
💡 Opportunity: Multiple high-impression keywords at positions 2–4 with 0% CTR
"garage beveren" → pos 3.57 · 54 impressions · 0 clicks. "auto garage beveren" → pos 2.62 · 13 impressions · 0 clicks. Position is not the problem — the title/description snippet shown in Google is not compelling enough to earn a click. Fix: improve meta descriptions for these specific queries (see Fix #3 below).

Action Plan — 4 Fixes in Priority Order
Fix #1 · This week · Highest priority
Resolve www vs non-www duplicate
Google is splitting 1,256 combined impressions between two URLs. Merging them into one will consolidate authority and push the real homepage from position ~14 (average of 4.3 and 23.4) to position 4–5 immediately — no content change needed.
Add to .htaccess (redirect non-www → www)
RewriteEngine On RewriteCond %{HTTP_HOST} !^www\. [NC] RewriteRule ^ https://www.%{HTTP_HOST}%{REQUEST_URI} [R=301,L]
Then verify canonical in index.html <head>
<link rel="canonical" href="https://www.layangaragebv.be/">
After fix — request re-indexing in GSC
GSC → URL Inspection → https://layangaragebv.be/ → Request Indexing
Impact: HIGH — immediate position gain
Fix #2 · This week · High priority
Redirect old WordPress sub-pages → main site
These pages return HTTP 200 with old content (confirmed by GSC impressions). Google ranks them but users don't click because the title/description is outdated. 301 redirects pass their existing ranking power to the correct page and fix the CTR issue.
Add to .htaccess (after Fix #1 rules)
Redirect 301 /diensten/motordiagnose/ https://www.layangaragebv.be/#diagnose Redirect 301 /diensten/band-en-wielservices/ https://www.layangaragebv.be/#services Redirect 301 /diensten/remreparatie/ https://www.layangaragebv.be/#services Redirect 301 /onderhoud/ https://www.layangaragebv.be/#services Redirect 301 /verkoop-wagens/ https://www.layangaragebv.be/#cars Redirect 301 /inventory/ https://www.layangaragebv.be/#cars Redirect 301 /cookiebeleid-eu/ https://www.layangaragebv.be/privacy.html
After adding — submit sitemap in GSC
GSC → Sitemaps → Submit → https://www.layangaragebv.be/sitemap.xml
Impact: HIGH — recovers 500+ stranded impressions
