Critical Issues Found
🚨 Issue #1 — CRITICAL: Two separate URLs indexed by Google
https://www.layangaragebv.be/ → 692 impressions · position 4.3 · 28 clicks
https://layangaragebv.be/ → 564 impressions · position 23.43 · 27 clicks

Google treated these as two different pages during the export window and split authority between them. The project canonical is now non-www: https://layangaragebv.be/. The correct fix is www → non-www 301 redirect plus canonical alignment, not the opposite.
⚠ Issue #2: Old WordPress URLs still indexed — now redirected instead of 404
GSC shows legacy WordPress URLs (/diensten/motordiagnose/, /verkoop-wagens/, etc.) ranked at positions 3–7 with 500+ combined impressions but near-zero clicks. Live testing on 16 June showed these URLs returned 404 after the static-site migration. Fix applied: 301 redirects from the old URLs to the matching landing-page sections, preserving users and SEO signals.

Action Plan — 4 Fixes in Priority Order
Fix #1 · Completed · Highest priority
Resolve www vs non-www duplicate using non-www canonical
The site standard is https://layangaragebv.be/. Keeping one canonical host prevents Google from splitting impressions, links and ranking signals between two homepage URLs.
Current .htaccess rule (redirect www → non-www)
RewriteEngine On RewriteCond %{HTTP_HOST} ^www\.layangaragebv\.be$ [NC] RewriteRule ^ https://layangaragebv.be%{REQUEST_URI} [R=301,L,NE]
Canonical in index.html <head>
<link rel="canonical" href="https://layangaragebv.be/">
Next step in GSC
GSC → URL Inspection → https://layangaragebv.be/ → Request Indexing
Impact: HIGH — consolidates homepage signals into one canonical URL
